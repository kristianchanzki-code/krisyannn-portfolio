## Featured Projects

### BLACKMING PAMS

BLACKMING PAMS is a private internal POS Asset Management System built around real operations workflows, including asset records, deployment, replacements, returns, repairs, custody, and history.

The production application and source code are private. Portfolio screenshots are anonymized, and operational details are redacted or replaced.

### SINKPESO

SINKPESO is a public, offline-first personal finance app created for Filipinos. It focuses on private, local-first tracking for expenses, wallets, bills, savings, recurring entries, and reports.

- Live app: https://sinkpeso.github.io/
- Source code: https://github.com/sinkpeso/sinkpeso.github.io

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 in a browser.

## Environment Variables

`.env.example` documents the optional environment variables used by the contact form and site URL configuration. Keep real credentials in a local environment file and never commit them.

## Validation

```bash
npm run build
```
